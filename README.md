# Ultimate AI Tools Hub & AI Resources Directory

> A comprehensive, interactive directory cataloging over 360+ curated AI tools and 33+ high-value AI guides, master prompts, workflows, and developer resources.

---

## 🚀 Overview

* **⚡ AI Tools Directory (`index.html`):** 363 curated AI tools categorized across 20+ specialized domains (Writing, LLMs, Voice, Image, Video, Coding, Marketing, 3D, Music, Productivity, Risky / Autonomous Agents, and more) with real-time instant search.
* **📚 AI Resources Hub (`resources.html`):** 33 curated prompt engineering guides, system prompts, roadmaps, cheat sheets, and practical research links.
* **✨ Modern UI/UX:** Ultra-dark theme (`#050505`), glassmorphic backdrop-blur cards, responsive CSS Grid layout, gradient glow accents, and zero third-party framework dependencies.

## 💻 Running Locally

Simply open `index.html` in any browser:
```bash
# Optional: Launch via Python lightweight HTTP server
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.
